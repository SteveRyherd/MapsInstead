Support

Most problems come down to one of the first three items. Each takes under a minute to check.

Fix it

Links still open Google's page or the App Store

1. Is the extension on? iPhone and iPad: Settings › Apps › Safari › Extensions › Remapped › Allow Extension. Mac: Safari › Settings › Extensions, Remapped ticked. The setup guide has pictures.

2. Is it allowed on Google? Same screen, under Permissions. Safari treats google.com, maps.google.com and your country's Google site separately, and "Ask" means the page loads untouched. Set each one to Allow, or choose Always Allow when Safari asks.

3. Was it Safari? Safari extensions only run in Safari. Links opened inside another app's built-in browser, or in Chrome, are not touched. Tapping the link's "Open in Safari" option, or sharing it to Safari, fixes that.

Then open the Remapped app and press Test it. If Apple Maps opens with directions to Apple Park, the extension is working and the problem is the specific link, so please report it below.

Google shows a "get the app" box

That box belongs to Google's web page, which means Remapped did not run on that page load. It dismisses the box for you when it can, but the real fix is the permission check above. If you keep seeing it, copy the address from Safari's address bar and report it.

The wrong place, or a map instead of directions

Google has dozens of link formats and new ones appear. Send the Google link and what you expected; each report becomes a permanent test case and the fix ships in the next update.

I want Google's page this time

Tap the Remapped button in Safari's toolbar and switch it off. On iPhone the button is in the menu at the left of the address bar. Links open normally until you switch it back on; the popup also shows how many links it has redirected so far.

Does it run in the background or drain the battery?

No. It only runs when a Google page is open in Safari, and it does its work in a few milliseconds when you tap a link.

Can I use it on my Mac too?

Yes, with the same purchase. Download it from the Mac App Store with the same Apple ID, then follow the Mac tab of the setup guide.

Report a problem

Open an issue at github.com/SteveRyherd/detour/issues, or email support@example.com. Include:

  • Device and OS version (for example iPhone 15, iOS 26.1)
  • Where you tapped the link (Google search, Messages, a website)
  • The link itself, copied from Safari's address bar or the share sheet

Replace the email address above with your real support address before launch. App Store Connect requires a working support URL, and this page is it.
