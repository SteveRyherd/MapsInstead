Maps Instead: screenshot checklist

Part A feeds the website (exact file names matter). Part B is for the App Store listing. Part C is the App Preview video.

Before you start

  • Light mode on every device. Portrait on iPhone and iPad.
  • Make sure the extension is on and allowed on Google sites before the "working" shots, and off for the Settings shots where you want the switch visibly being turned on.
  • iPhone screenshot: Side button + Volume Up. Mac window: Shift-Command-4, then Space, click the window. Mac full screen recording: Shift-Command-5.
  • Annotate afterwards in Preview: Tools › Annotate › Rectangle, red, border 4. One red rounded box around the thing to tap.
  • AirDrop phone shots to the Mac, rename to the file names below, put them in docs/images/.
