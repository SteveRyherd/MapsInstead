Privacy Policy

Last updated: November 2026

The short version

Detour collects no data. None. There are no analytics, no crash reporters, no advertising identifiers, no accounts and no servers run by us.

What the extension does

Detour is a Safari extension. When you tap a Google Maps link, it rewrites that link into an Apple Maps link on your device and opens it. The conversion happens entirely inside Safari, in plain JavaScript you can read on GitHub.

What it stores

Two values, kept only on your device using Safari's local extension storage: whether the extension is switched on, and a count of how many links it has redirected so you can see it working. Deleting the app deletes them. Nothing is synced or sent anywhere.

The one network request

Google's shortened map links (maps.app.goo.gl, goo.gl/maps, g.page) do not contain the destination; the destination is only revealed when the link is followed. For those links, and only those, Detour asks Google's redirect service where the link goes, in the same way Safari would if you simply opened it. Google sees that request as it would any visit to the short link. Detour sends no cookies with it and adds no identifying information. Detour never contacts any other server.

What it can see

Safari only lets Detour run on the websites you allow. Detour asks for Google's domains and Google's short-link domains, nothing else. It cannot read or change any other website.

Apple Maps

Once a link is handed to Apple Maps, Apple's own privacy policy applies to what you do there.

Children

Detour collects no data from anyone, including children.

Changes

If this policy ever changes, the new version will be published at this address with a new date, and the change will be visible in the project's public source history.
